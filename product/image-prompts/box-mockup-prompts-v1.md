# Box & Component — 3D Mockup Image Prompts

**Last Updated:** April 9, 2026
**Status:** Draft v1
**Purpose:** Image generation prompts for 3D structural mockups of each box type and component. These are manufacturer communication images — clean studio shots showing how each flat dieline folds into a finished 3D form. NOT marketing images. Use neutral placeholder graphics (solid color panels or simple labels) so the focus stays on form, structure, and assembly.
**Reference:** All dimensions from dimensions-spec-v10.md. Dielines in `dielines/` folder. Templates in `templates/` folder.

**Visual direction:** Clean white/light gray studio background. Soft even lighting, minimal shadows. No branding, no Brad, no narrative content — just neutral structural mockups. Material callouts in each prompt match the spec (matte black paperboard, corrugated, etc.). These images answer the question: "What does this flat thing become when you fold it?"

**Usage:** Generate each prompt, then share the resulting images alongside the corresponding dieline PDF and template file when communicating with manufacturers/sourcing partners.
