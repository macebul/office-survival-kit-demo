# Cubicle Shank — Surface Map (Complete Copy Specification)

**Last Updated:** June 19, 2026
**Purpose:** Every word of copy that goes on the Cubicle Shank carded blister pack, with exact surface placement. This document is self-contained — no other document is needed to execute the design.
**Card dimensions:** 13.25" wide × 10.75" tall, L-shaped (4.75" × 3.75" notch cut from upper-left corner to accommodate the Mug Shot box)
**Card material:** 18pt matte black paperboard, printed both sides
**Blister:** Clear PETG thermoformed, glued to card front. Narrow elongated bubble holding one matte black tactical ballpoint pen (5.5" × 0.6"). Blister depth: 0.65".

---

## CARD FRONT (display face — pen visible through blister)

### Element 1: Brand Logo (top of card, near hang hole)

```
ELEVATE CO.
```

### Element 2: Division Name + Tagline (upper area, below or beside brand logo)

```
O3 — Office Offense Outfitters
Because it keeps you more alive than O2.
```

**Design note:** "Because it keeps you more alive than O2." should be visually subordinate to the division name — smaller type, parenthetical feel, or tucked directly under the O3 line. It explains why the division is called O3 (ozone keeps you more alive than oxygen). It should read as a clever aside, not a headline.

### Element 3: Division Slogan (below division name block)

```
Arming the 9-to-5 since the 5-to-9.
```

**Design note:** Needs paired icons flanking or integrated with this line:
- A clock/briefcase icon associated with "9-to-5" (the work shift)
- A jail cell/bars icon with figure associated with "5-to-9" (the prison sentence)

The icons clarify that "5-to-9" is a prison sentence, not evening hours. This is the primary division slogan and should be more prominent than the O2 tagline above it.

### Element 4: Product Name (hero headline — largest text on the card)

```
CUBICLE SHANK
```

**Design note:** This is the dominant visual element. Large, bold, condensed. Should read from several feet away.

### Element 5: Primary Subtitle (directly below product name, smaller)

```
The pen that ends sentences. May also extend yours.
```

### Element 6: Primary Tagline (below the blister area)

```
Writes in black. Moonlights in red. Racks up PTO and a body count spread.
```

### Element 7: Good Shanking Seal of Approval (lower corner — badge element)

**Format:** Oval/shield seal with ornate border and ribbon, styled as a Good Housekeeping Seal parody.

**Text on the seal:**

```
GOOD SHANKING
SEAL OF APPROVAL
```

**Center illustration:** Retro-illustrated Carl (custodial worker) with mop, looking at someone who is clearly not okay. Carl is giving a resigned, calm assessment. Southern. Doesn't say much.

**Sub-text below or on ribbon:**

```
"That'll buff out." — Carl, Custodial
```

### Element 8: Quantity Line (bottom edge, small institutional text)

```
Qty: 1 pen. Ink refills sold separately. Accessories sold very separately.*
```

**Footnote (smaller text, marked with the asterisk):**

```
*The Cubicle Shank Premium Experience™ includes: holster (thigh or
desk-mount), burner phone (pre-loaded), getaway car (compact), and one (1)
character witness named Doug. Doug has been briefed. Doug will not break.
```

**Design note:** The footnote is the full Premium Experience™ accessories list. All text must appear — holster, burner phone, getaway car, and Doug. The ™ on "Premium Experience" is intentional. This is the locked version. If space is tight, the condensed alternate is: "Premium Bundle includes: getaway car (compact), burner phone (pre-loaded), and one (1) character witness named Doug. Doug has been briefed. Doug will not break."

### Element 9: Fine Print Line 1 (bottom edge, fine print size — 7pt)

```
Patent pending. Trial also pending. Jury still out. Literally.
```

### Element 10: Fine Print Line 2 (bottom edge, fine print size — 7pt)

```
Tested on animals would've been easier to explain to HR.
```

### Element 11: Hidden Copy Under Pen Blister (printed on card, covered by blister plastic and pen — revealed when pen is removed)

```
CUSTOMER QUESTION: "Does it come in red?"
ANSWER: Eventually.
```

**Design note:** This copy is a Layer 4 discovery — the recipient removes the pen from the blister and finds this printed on the card underneath. It should be styled as a small customer Q&A block. Not visible until the pen is taken out.

## NOTCH TREATMENT (upper-left corner — deferred)

The 4.75" × 3.75" notch in the upper-left corner of every blister card exists because the Mug Shot box sits in that corner of the briefcase. This notch will have a design treatment that visually connects to the adjacent mug box, making it feel intentional rather than structural.

**Options under consideration:**
- Prison cell bars visual along the notch edges
- Evidence tape / crime scene tape border treatment
- Ruler/measurement lines continuing from the mug box surface
- Combination treatment that works across all 7 blister cards

**Decision deferred** until mug box packaging design and copy are finalized. The mug box face visible from the top-down briefcase view (likely the front cover) will be adjacent to this notch edge — the two surfaces need to be developed together so they interact visually.

**Note:** Each of the 7 blister cards may get a different notch treatment, or all 7 may share the same treatment. This decision is part of the deferred scope.

### PROMPT NOTES

- These prompts are for Midjourney v6.1
- AI image generators struggle with exact text reproduction — the generated images will approximate the text layout and feel but individual words may be garbled or misspelled. The purpose of these mockups is to validate the **layout, density, visual hierarchy, and overall feel** — not to produce print-ready copy.
- The front prompt omits the hidden under-blister copy (Element 11: "Does it come in red?" / "Eventually.") because the pen and blister would cover it in the photograph.
- The front prompt omits the L-shaped notch (upper-left corner) because the notch treatment is deferred pending mug box design.
- To get a 3×3 grid of variations, prefix either prompt with "Show me a 3x3 grid of" and adjust `--ar` if needed.
- The `--s 250` flag sets stylization. Adjust up for more artistic interpretation, down for more literal rendering.
