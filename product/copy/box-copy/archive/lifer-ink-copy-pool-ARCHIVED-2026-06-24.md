**Status Tags:**
- **LOCKED** — Approved and final. Not changing.
- **KEEP** — User explicitly approved during review.
- **WY-KEEP** — Passes the updated WY voice filter (warm, cheerful, 7 mechanical rules). Awaiting user review.
- **MAYBE** — User said "maybe," "has potential," or "could work with changes."
- **NEEDS-REWRITE** — Strong concept, wrong voice. Rewrites provided below.
- **UNREVIEWED** — Never received specific user feedback.
- **DOWNGRADED** — Previously KEEP or MAYBE, no longer passes updated standards.
- **NEW** — Generated in this session in the correct WY voice.

## KEY LEARNINGS (carried forward + new)

1. **The setup IS the joke.** BRAD-21 shortened versions lost the comedy. Cutting setup kills the punchline. Keep full length, find bigger surfaces.
2. **Descriptive is not funny.** BD-10 round was "all descriptive, no comedy mechanics." Every line needs a reversal, subversion, or comedic technique. If it just describes something straight, it's not a joke.
3. **Downer energy kills it.** BRAD-21 versions listing failures (businesses, marriages) felt sad, not funny. Brad should be SELLING temporariness as premium, not coping with impermanence. Playful/proud Brad, not defensive Brad.
4. **Escalate into absurdity, not tame down.** CARE-5 kept going safe when the user wanted knife-pulling, dominance standoffs, and Cubicle Shank crossovers.
5. **Brad quotes need clear comedic targets.** Story to wrong conclusion. Each sentence advances. Nothing wanders.
