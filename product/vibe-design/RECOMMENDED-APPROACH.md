# Execution Plan: Office Survival Kit -- Packaging Design

## What the Designer Does

Take the copy, images, dimensions, and dielines provided by the product owner and lay them out on each packaging surface so they look good, read well, and feel like real products. Deliver print-ready files.

**The designer does NOT figure out:**
- How items fit inside the briefcase (product owner solves this)
- What type of packaging each item uses (already decided)
- Dimensions of each package (provided)
- Dielines / structural templates (provided)
- Copy (provided as-is, designer does not write or edit)

The Design Brief (`DESIGN-BRIEF-MASTER.md`) has all the creative direction. This document is the practical plan for getting the work done.

---

## Execution Order

### Step 1: Set Up the System

Before designing any individual item:
- Pick 2-3 fonts (heading, body, accent/fine print) -- see typography guidance in the Design Brief
- Mock up the briefcase exterior front face in 2-3 accent color options (the brand-level accent color is undecided -- see brief for details). Present for approval.
- Create reusable elements: barcode style, fictional regulatory marks, division logo template, QC stamp (Gary), fine print formatting

**Approval gate:** Product owner picks the accent color direction and confirms the font choices before anything else moves forward.

---

### Step 2: Briefcase Exterior

- Design all 6 exterior surfaces
- Interior bottom is TBD (product owner is still writing the final joke for it -- leave a placeholder)
- This is the first real test of whether the system looks right

**Approval gate:** Product owner reviews the briefcase. If the tone and quality feel right, proceed to items.

---

### Step 3: One Complete Item (Proof of Concept)

- Pick one of the card deck items (it has the most surfaces: card box + blister pack front + blister pack back)
- Design every surface of that one item
- This becomes the quality benchmark and template for all remaining items

**Approval gate:** Product owner reviews the complete item. If it works, this is the standard for everything else.

---

### Step 4: Remaining Items

Design all surfaces for the remaining items. Suggested order:

1. Other two card deck items (similar format to the proof of concept)
2. Cubicle Shank -- pen blister pack
3. Lifer Ink -- tattoo blister pack
4. Turf Tags -- sticker blister pack
5. Contraband -- gag blister pack (empty stapler-shaped cavity, copy-only, no product inside)
6. Mug Shot -- windowed box (different format, do last)

---

### Step 5: Final Check

- View all items together as they'd appear stacked in the briefcase
- Print at actual size to verify all copy is legible
- Check consistency across items (fonts, sizes, element placement)
- Final QC on print specs (bleed, CMYK, resolution, dieline alignment)
- Deliver packaged files

## Designer Requirements

- Packaging design experience (consumer products, not just digital/web)
- Print production proficiency (bleed, dielines, CMYK, prepress)
- Adobe Illustrator or equivalent for vector print files
- Ability to create clean institutional-style icons and logos

## Known Risks

| Risk | What to do about it |
|------|---------------------|
| Dimensions change after design starts | Start with the type system and visual direction (Step 1). Final layouts adapt when dimensions lock. |
| Copy changes after layout is done | Keep copy as editable text layers, not baked into artwork. Updates should be text swaps. |
| Branding changes (Brad / Elevate) | Keep branding elements on separate layers. Swapping a name or logo should take minutes. |
| Magazine inclusion TBD | Not in scope. If added later, it uses the same type/color system. |
| Designer makes it look like a gag gift | Review Step 1 mockups carefully. The brief is explicit: the design must look like real products. Flag any novelty/joke signals early. |
| Legibility issues at print size | Enforce minimums from the start (9pt body, 7pt fine print). Print test at actual size during Step 3 before committing to all items. |

## Typography Starting Points

The designer should propose fonts, but here are starting directions:

**Option A -- Institutional/Government:**
- Heading: Interstate or FF DIN
- Body: Helvetica Neue or Akkurat
- Accent: Courier or IBM Plex Mono

**Option B -- Corporate/Premium:**
- Heading: Gotham or Proxima Nova
- Body: Source Sans Pro or National
- Accent: Space Mono or Roboto Mono

**Option C -- Industrial/Tactical:**
- Heading: Barlow Condensed or Oswald
- Body: Inter or Work Sans
- Accent: JetBrains Mono or Fira Code

**What matters more than the specific fonts:**
- Heading font has authority, doesn't look playful
- Body font is invisible and reads well at 9pt
- Accent font looks institutional/technical
- All three create clear hierarchy through contrast
