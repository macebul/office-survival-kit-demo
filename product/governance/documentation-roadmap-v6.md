# Office Survival Kit — Documentation Roadmap

**Purpose:** Complete list of documents needed to take this product from concept to launch, organized by phase and priority.

**Version:** v10
**Last Updated:** May 22, 2026

**Architecture note (March 10, 2026):** Each document in this project has one specific job. No specs are duplicated across documents. If you need to know something, consult the authority document for that topic — see the Cross-Reference Map below.

**Major pivot note (March 13, 2026):** The product underwent a significant creative pivot. Key changes: (1) items reduced from 13 to 7 + 1 empty recess, (2) each tray item now has individual retail-style boxes (5 tuck-end + 1 tray-and-sleeve for pen), (3) outer Amazon box added as outermost packaging layer, (4) Corporate Parole Passport replaced by Activity Guide (16-page saddle-stitched booklet), (5) evidence bag and guide cards removed, (6) Pelican-style die-cut recesses retained but sized for product boxes. Five core documents updated: Item Specs v5→v6, Packaging Spec v8→v9, Dimensions Spec v9→v10, Copy Doc v5→v6, Documentation Roadmap v4→v5. Previous versions archived.

**Art direction pivot note (May 15, 2026):** Doc Set 1 booklet images pivoted from mid-century modern illustration (angular geometric faces, flat color, retro poster feel) to **photorealistic corporate stock photography** with layered absurdity. All existing mid-century image prompts archived at `archive/mid-century-art-direction/`. New art direction governed by: Art Direction Brief v1, Image Prompt Spec v1, and Prompt Conversion Examples. Brad character reference doc pending. All existing booklet image prompts to be rewritten to new format.

**Magazine format pivot note (May 22, 2026):** Doc Set 1 pivoted from 12-page, 5.5x7" booklet to **30-page, 8.5x11" glossy magazine** titled *ELEVATE — The Official Magazine of Elevate Co.* Voice direction shifted from deadpan/institutional to **enthusiastic, upbeat, persuasive** (Fallout shelter ads, SkyMall, Russell Brunson energy). Three-act narrative structure preserved but reframed as magazine editorial sections. Product ads for kit items woven between editorial features. Previous booklet docs archived at `archive/doc-set-1-booklet/`. Magazine structure governed by: Magazine Structure v1 (`product/copy/magazine-structure-v1.md`).
