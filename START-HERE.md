## House rules for this folder

1. **One card file per item**, in `product/items/<item>/`. New lines get drafted in the working doc and promoted to the card file only after Johnny's reaction.
2. **Put a date on everything.** New files carry a date in the header. Batches and archives carry a date in the file or folder name. Status notes say when they were written.
3. **Archive, never delete.** Superseded files go to `archive/<YYYY-MM-DD>-<reason>/`, keeping their original path. Nothing lives in an "archive" subfolder anywhere else.
4. **Johnny's words go in the feedback log, verbatim.** Anything he writes or rewrites is locked as he wrote it.
5. **Update this file whenever an item's status changes.**
