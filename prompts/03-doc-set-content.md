# Creative Session: Doc Set Content & Format Decisions

## Context

The **Office Survival Kit** briefcase contains **three doc sets** discovered at different layers during unboxing. Each doc set is a physical printed piece that deepens the narrative and adds replay value. They need to feel different from each other — different format, different voice, different purpose.

### The Two Characters
- **Brad Sterling (B.S.)** — Founder & CVO, Elevate Co. Polished, corporate, zero self-awareness. His product copy is competent office humor in straight-faced formats.
- **The OG (Owen Granger)** — Original kit creator. Dry, deadpan, institutional. Hidden throughout the kit via sticky notes and smuggled text.

### World Rules
The office IS a prison. Vocabulary: yard, cell, block, inmate, issued, contraband, parole, sentence, intake, release.

### Doc Set 1 — On Tray 1 (discovered after lid opens, under booking frame)
**Location:** Rests on top of Tray 1 items. First document the recipient reads.
**Timing:** Early in unboxing — sets the tone for everything that follows.
**Format:** TBD (see options below)

### Doc Set 2 — On Tray 2 (discovered when Tray 1 is lifted)
**Location:** Rests on top of Tray 2 items. Second document discovered.
**Timing:** Mid-unboxing — the recipient is now invested in the narrative.
**Format:** TBD (see options below)

### Doc Set 3 / Manual 3 — "Office Survival Manual Volume III"
**Location:** Rests on TOP of the back zone compartment cover (visible when Tray 2 is lifted, before compartment is opened).
**Timing:** Late unboxing — just before the finale mug reveal.
**Format:** LOCKED — 16-page saddle-stitched mini booklet (~5.5" × 4.25" closed, quarter-letter landscape). 1–2 color (black + possible accent). Underground document aesthetic.
**Voice:** Pure OG. This is his extended voice — the first time the recipient gets more than a sticky note from him.

---

## Decision Needed: Doc Set 1 & 2 Format

### Direction A: Nemesis vs. OG Defacement
- **Doc Set 1:** Brad's welcome materials — product catalog, letter from founder, warranty card. 100% corporate voice, polished, sincere. Brad genuinely believes this is premium content.
- **Doc Set 2:** Brad's product guide, BUT defaced by OG — sticky notes slapped over Brad's copy, corrections, crossed-out text, margin annotations. Two voices fighting over the same document. This is where the "wait, who's writing these notes?" becomes "oh, there's a whole war happening."

### Direction B: OG Institutional Documents
- **Doc Set 1:** OG's intake documents — institutional forms, processing paperwork (name, department, years served, cell assignment). Pulls the recipient into the prison-office world.
- **Doc Set 2:** OG's smuggled manual excerpts — torn pages, underground survival tips, field notes. Feels illicit, like contraband.

### Direction C: Hybrid
- **Doc Set 1:** Brad's welcome letter + product catalog (Direction A, first half)
- **Doc Set 2:** The same document template, but OG has gotten to it — defaced, annotated, corrected. The contrast between Doc Set 1 (pristine Brad) and Doc Set 2 (OG-vandalized Brad) tells the story.

**Key requirement:** Doc Sets 1 and 2 must look and feel different from each other AND from Doc Set 3.

### For Doc Set 3 (Manual 3 — "Office Survival Manual Volume III"):
The format is locked (16-page booklet). I need content for all 16 pages:

**Existing page plan:**
- **Cover:** Title, OG's mark/stamp, "NOT FOR DISTRIBUTION"
- **Inside cover:** OG's intro — who he is, why this exists
- **Pages 1–2:** Cubicle Shank field notes + activities
- **Pages 3–4:** Lifer Ink field notes + activities
- **Pages 5–6:** Turf Tags field notes + activities
- **Pages 7–8:** Card decks (combined) — deployment scenarios
- **Pages 9–10:** Confiscated Stapler — backstory, incident report, legend
- **Page 11:** Mug Shot — brief mention (item speaks for itself)
- **Page 12:** Survival record — fill-in section (name, start date, days survived)
- **Back cover:** Final OG message

**What I need for the booklet:**
1. **Full copy for all 16 pages** (or at least detailed outlines + key copy for each spread)
2. **2–3 interactive elements** (checkboxes, fill-in fields, bingo card, etc.)
3. **The incident report for the stapler** — what happened with Incident #147?
4. **OG's intro** — who is he? Why did he make the original kit? (Never fully explained — just enough to make you curious)
5. **The final message** on the back cover — this is OG's goodbye. Make it land.

## Tone Calibration

| Element | Voice | Energy |
|---------|-------|--------|
| Doc Set 1 | Brad OR OG (depends on direction) | Welcoming, sets the stage |
| Doc Set 2 | Brad+OG hybrid OR pure OG | Escalating, narrative deepens |
| Doc Set 3 | Pure OG | Intimate, rewarding, the real heart of the kit |

The emotional arc across all three: **corporate facade → cracks appear → the real thing underneath.**

---

## Constraints
- No profanity
- All content must work for a general audience (giftable in any workplace)
- Doc Set 3 is 1–2 color only (black + one accent) — design must work without full color
- Each doc set should have replay value (funny on second read, not just first)
- OG's voice in Doc Set 3 should make the recipient feel like they found something real — not a product, but a person
