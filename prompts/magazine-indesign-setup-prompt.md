## What's Changed — The New Magazine Format

### Format Shift
- **Old:** 5.5x7" portrait, 12-page booklet, startup brand book aesthetic
- **New:** 8.5x11" portrait, 30-page magazine, professional magazine aesthetic

### Voice Shift
- **Old:** Deadpan, dry, institutional — nobody notices the horror
- **New:** Enthusiastic, upbeat, playful, persuasive — everyone is aggressively enthusiastic about the horror

### Design Shift
The magazine needs to look like a **real magazine**, not a brand book. Think:
- Vibrant, colorful, well-staged photography (not muted tones)
- Magazine editorial layouts (feature articles, product ads, advice columns, infographics)
- Professional but with personality — the kind of magazine that has a clear visual identity
- Each section uses a different editorial format (real estate listing, gear review, investigative journalism, fashion editorial, etc.)

The previous booklet was **muted, clean, minimal, premium brand book.** The new magazine is **vibrant, varied, energetic, professional editorial.** The color palette and typography need to support this shift.

### Key Observations for Typography Decisions

1. **This magazine has many different editorial formats.** A real magazine uses typography to signal "you're in a different section now" — but stays cohesive through a shared type system. I need paragraph styles flexible enough to handle feature articles, product ads, infographics, advice columns, and luxury reveals.

2. **Some pages are loud and energetic** (product ads, gear reviews, infographics). Some pages are **quiet and emotional** (the mug reveal on pp.28-29). The type system needs to support both.

3. **The cover has headline teasers** around the margins like a real magazine cover — that's a specific typographic treatment.

4. **Product ads** need their own typography hierarchy — headlines, subheads, testimonials, spec tables, fine print, CTAs.

5. **The advice column** needs a distinct visual voice — reader letters vs. Brad's answers.

6. **Infographics** (pp.14-15) need data-friendly typography.

7. **The masthead/TOC** needs to look like a real magazine masthead.
